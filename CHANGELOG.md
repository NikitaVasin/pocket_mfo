# История каталога Pocket MFO

## 1.1.0 — 2026-10-02

Изменения относительно 1.0.1:

- Новый Go-плагин **AppMetrica**: общая конфигурация для Partner Links и Push, отдельная вкладка, получение SDK/Post API ключей по OAuth-токену и Application ID. Заполненность параметров, доступ к API и реальная доставка различаются. Проверка доступа выполняет только чтение.
- **Partner Links:** провайдеры определяются Go-кодом; встроенный пресет — Rafinad New. Отсутствующий секрет постбека генерируется, сохраняется и доступен суперпользователю в свёрнутой инструкции провайдера. Конверсии представлены отдельным табом с карточками, фильтрами и просмотром записи.
- **Push:** общие ключи читает из AppMetrica; скорость по умолчанию задаётся кодом. Новое поле `Campaign.SendRate`: 0 — наследовать, 100–5000 — переопределить. Скорость фиксируется в снимке запуска. При первом переносе и последующей смене ID сохраняется защита существующих устройств и незавершённых запусков.
- **Dynamic Link:** при подключённом Partner Links автоматически добавляется категория `offers` без перезаписи существующих параметров. Доступен Go API `RegisterDefaultCategory`.
- **Currency Rates:** отдельная панель в верхней навигации с датой, поиском, курсом за единицу валюты и сравнением с предыдущей сохранённой датой.
- Общая навигация скрывает коллекции плагинов в Collections, включая системные, закреплённые и поиск; схемы остаются доступны редакторам связей. Затронуты также MCP, Singleton и Variants. Schema Lock разрешает точные административные маршруты AppMetrica, сохраняя серверные ограничения.
- **Example:** демонстрационный партнёр подключается только через `DEMO_PARTNER_ENABLED=1` до первого запуска. Миграция `1789948810_remove_legacy_demo_partner.go` удаляет только неизменённый старый пример; изменённые провайдеры/ссылки и история конверсий сохраняются.

**API и совместимость.** Go-вызовы и форматы клиентских записей сохранены; новые API добавлены в AppMetrica, Dynamic Link и Push. HTTP-редактирование структуры провайдеров, имён событий, сроков хранения Partner Links и скорости Push по умолчанию больше не поддерживается: перенесите управление этими параметрами в Go. После подключения AppMetrica настройки аналитики через Configure/API потребителей менять нельзя — используйте общий модуль. UI служебных коллекций заменён страницами плагинов; прямой доступ остаётся в рамках серверных правил. Dart/Flutter-пакеты и их публичный API не изменены. PocketBase v0.40.4, Go 1.27 и SDK не обновлялись.

**Обновление.** Перед первым запуском сделайте бэкап; зарегистрируйте AppMetrica перед Partner Links/Push, перенесите OAuth-токен и прежний Application ID в её Managed-конфигурацию. Старые параметры импортируются один раз транзакционно; конфликт ID останавливает перенос. SDK/Post API ключи сервер получает автоматически при наличии прав OAuth. Сохраните прежние ID провайдеров и секреты действующих постбеков. Дополнительные ручные миграции production-схемы и клиентских данных не требуются: служебную коллекцию создаёт плагин, demo-миграции в production не подключать. Старые конфигурации сохраняются, но не синхронизируются с новым модулем; для отката после изменения настроек нужен согласованный бэкап.

Подробный порядок — [руководство интеграции](docs/AI_INTEGRATION.md#обновление-с-101-до-110), требования — [совместимость](docs/COMPATIBILITY.md), проверки и ограничения — [отчёт выпуска](docs/RELEASE_1.1.0.md). Локальная фиксация версии не означает публикацию в GitHub.

## 1.0.1 — 2026-09-24

- Dynamic Link: общие настройки и категории в отдельной вкладке админки, категории представлены табами; поле ссылки содержит URL, категорию и заголовок WebView. По умолчанию используется внешний браузер, общие настройки защищены от удаления.
- Partner Links: карточки ссылок и настройки разделены по вкладкам; Schema Lock защищает настройки AppMetrica и провайдеров. Служебные коллекции ссылок скрыты из боковой панели.
- Админка: исправлены переход в Collections, загрузка Dynamic Link после обновления страницы, селекторы, переключатели и отступы. Предпросмотр Typed Config ограничен двумя строками с количеством и типами блоков.
- Flutter: восстановление гостевой сессии и push-регистрации после ошибок хранилища; настройка User-Agent больше не зависит от сохранения cookies.
- Push: ошибочная запланированная аудитория не блокирует остальные рассылки; тестовые устройства проверяются до сохранения запуска, ошибки хранения сохраняют возможность повтора.
- MCP: исправлена проверка лимита JSON-тела. Уточнены подсказки о дедупликации партнёрских событий; локальный Docker-стенд запускается без длительного кеширования расширений админки.

При обновлении согласуйте общие настройки и категории Dynamic Link: они переопределяют ранее сохранённые индивидуальные параметры ссылок; без категории применяется общая политика. Сервер и Dart/Flutter-пакеты используйте из одного выпуска. В примере добавлена миграция `1789948809_dynamic_link_categories.go`; demo-миграции не предназначены для production.

Версии PocketBase и SDK не изменены. Результаты ревью и границы проверок — [в отчёте](docs/REVIEW_2026_09_24.md). Эта запись не означает публикацию тега `v1.0.1` в GitHub.

## 1.0.0 — 2026-09-23

Первый выпуск каталога: десять Go-плагинов PocketBase и шесть Dart/Flutter-пакетов, нативные расширения админки, серверный и Flutter-примеры.

- Контент: Polymorphic Relation, Variants, Typed Config, Singleton, Dynamic Link.
- Интеграции: Partner Links, Push, MCP, Currency Rates; защита схемы через Schema Lock.
- Независимое распределение экспериментов и подписанные контексты показанного контента для событий и поздних конверсий; дедупликация подтверждённых статусов и Revenue.
- Типизированные конфигурации экранов: формы и карточки без JSON, mapping источников, каскадное удаление зависимых блоков и генерация Dart DTO.
- Flutter-фасад для гостевой/обычной авторизации, аналитики, ссылок и опциональных нативных пушей; нижние пакеты доступны отдельно.
- Инструкции для агентов, обязательные критерии совместимости, проверки в независимых проектах-потребителях и CI.

Проверенная связка: PocketBase v0.40.4, Go 1.27.0, Flutter 3.47.5 / Dart 3.13.4. Перед интеграцией обязательны [критерии совместимости](docs/COMPATIBILITY.md). Результаты локальных тестов и границы проверки внешних служб — [в отчёте](docs/RELEASE_READINESS_2026-09-23.md).

Тег `v1.0.0` обозначает выпуск всего каталога. Публикация тега в GitHub и проверка GitHub Actions — отдельные действия по [инструкции](docs/PUBLISHING.md); запись в журнале не утверждает, что они уже выполнены.
