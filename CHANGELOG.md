# История каталога Pocket MFO

## 1.0.1 — 2026-09-24

- Dynamic Link: общие настройки и категории в отдельной вкладке админки, категории представлены табами; поле ссылки содержит URL, категорию и заголовок WebView. По умолчанию используется внешний браузер, общие настройки защищены от удаления.
- Partner Links: карточки ссылок и настройки разделены по вкладкам; Schema Lock защищает настройки AppMetrica и провайдеров. Служебные коллекции ссылок скрыты из боковой панели.
- Админка: исправлены переход в Collections, загрузка Dynamic Link после обновления страницы, селекторы, переключатели и отступы. Предпросмотр Typed Config ограничен двумя строками с количеством и типами блоков.
- Flutter: восстановление гостевой сессии и push-регистрации после ошибок хранилища; настройка User-Agent больше не зависит от сохранения cookies.
- Push: ошибочная запланированная аудитория не блокирует остальные рассылки; тестовые устройства проверяются до сохранения запуска, ошибки хранения сохраняют возможность повтора.
- MCP: исправлена проверка лимита JSON-тела. Уточнены подсказки о дедупликации партнёрских событий; локальный Docker-стенд запускается без длительного кеширования расширений админки.

При обновлении согласуйте общие настройки и категории Dynamic Link: они переопределяют ранее сохранённые индивидуальные параметры ссылок; без категории применяется общая политика. Сервер и Dart/Flutter-пакеты используйте из одного выпуска. В примере добавлена миграция `1789948809_dynamic_link_categories.go`; demo-миграции не предназначены для production.

Версии PocketBase и SDK не изменены. Результаты ревью и границы проверок — [в отчёте](docs/REVIEW_2026_09_24.md). Эта запись не означает публикацию тега `v1.0.1` в GitHub.

## 1.0.0 — 2026-09-23

Первый выпуск каталога: десять Go-плагинов PocketBase и шесть Dart/Flutter-пакетов, нативные расширения админки, серверный и Flutter-примеры.

- Контент: Polymorphic Relation, Variants, Typed Config, Singleton, Dynamic Link.
- Интеграции: Partner Links, Push, MCP, Currency Rates; защита схемы через Schema Lock.
- Независимое распределение экспериментов и подписанные контексты показанного контента для событий и поздних конверсий; дедупликация подтверждённых статусов и Revenue.
- Типизированные конфигурации экранов: формы и карточки без JSON, mapping источников, каскадное удаление зависимых блоков и генерация Dart DTO.
- Flutter-фасад для гостевой/обычной авторизации, аналитики, ссылок и опциональных нативных пушей; нижние пакеты доступны отдельно.
- Инструкции для агентов, обязательные критерии совместимости, проверки в независимых проектах-потребителях и CI.

Проверенная связка: PocketBase v0.40.4, Go 1.27.0, Flutter 3.47.5 / Dart 3.13.4. Перед интеграцией обязательны [критерии совместимости](docs/COMPATIBILITY.md). Результаты локальных тестов и границы проверки внешних служб — [в отчёте](docs/RELEASE_READINESS_2026-09-23.md).

Тег `v1.0.0` обозначает выпуск всего каталога. Публикация тега в GitHub и проверка GitHub Actions — отдельные действия по [инструкции](docs/PUBLISHING.md); запись в журнале не утверждает, что они уже выполнены.
