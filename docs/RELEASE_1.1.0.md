# Проверки выпуска 1.1.0 — 2026-10-02

Состав и действия при обновлении: [CHANGELOG](../CHANGELOG.md), [руководство интеграции](AI_INTEGRATION.md#обновление-с-101-до-110), [совместимость](COMPATIBILITY.md). Выпуск содержит одиннадцать Go-плагинов и шесть неизменённых Dart/Flutter-пакетов. PocketBase v0.40.4, Go 1.27, Flutter 3.47.5 / Dart 3.13.4 сохранены.

## Ревью

Исправлены обход проверки Application ID при первом переносе Push в AppMetrica и удаление изменённого демонстрационного провайдера при очистке example. Для отказа переноса проверены откат и отсутствие частичных изменений; для очистки — сохранение изменённых mapping, расположения секрета, параметров открытия и активности ссылки. Чтение приложения AppMetrica объединено для подключения и проверки доступа; неверный ID, повреждённый и слишком большой ответ не сохраняют настройки и не подтверждают готовность.

## Выполненные локальные проверки

- Полный `go test -race ./...`, `go vet ./...`, `go build ./...`, `go mod verify` — успешно.
- Playwright — **102 теста**, обычный стенд и Schema Lock, светлая и тёмная темы.
- Docker smoke — сборка, health, встроенная админка, постбек и сохранность данных после перезапуска; использован отдельный временный Compose project.
- `test:partner` — redirect/postback, поиск, настройки, обе темы и мобильный размер.
- `fvm flutter pub get --enforce-lockfile`, Flutter analyze, Dart analyze для DTO — успешно; lockfile не изменён.
- Dart — **3 теста**, Flutter — **93 теста**; Typed Config DTO smoke — успешно.
- `test:integration` — обновлённые примеры Go-регистрации и Flutter-фасада компилируются в независимых проектах-потребителях.
- Flutter web-сборка без внешнего CDN и `test:flutter` — успешно: гостевая сессия, событие, офферы, свои заказы и ожидаемая ошибка resolve на ненастроенном тестовом сервере.
- `test:repository` и `git diff --check` — успешно. Пользовательская БД, ключи окружения и результаты тестов не включены в выпуск.

`govulncheck v1.8.0` под toolchain проекта не обнаружил уязвимых вызовов или импортируемых пакетов. На уровне модуля `golang.org/x/crypto v0.57.0` отмечен **GO-2026-5932** для неиспользуемого `openpgp`; исправленная версия в базе не указана. Зависимости ради этого не обновлялись.

## Границы проверки

Нативные Android/iOS исходники и зависимости в этом выпуске не менялись; APK и iOS Simulator заново не собирались. Живые AppMetrica/Firebase/APNs, кабинеты партнёров и доставка на устройства не проверялись. Локальные проверки не заменяют эти сценарии и CI на GitHub. Коммит и тег выпуска создаются локально; публикация требует отдельного действия.
