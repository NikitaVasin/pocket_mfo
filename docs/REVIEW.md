# Первичное ревью плагинов

Исторический отчёт для первых четырёх плагинов. Актуальный состав и результаты полной проверки — [готовность к публикации, 23.09.2026](RELEASE_READINESS_2026-09-23.md).

Проверены Polymorphic Relation, Variants, Singleton и Schema Lock: серверные хуки, транзакции, служебная схема, HTTP API, интеграция с админкой, тестовые стенды и документация. Целевая версия PocketBase — v0.40.4.

## Исправленные проблемы

| Проблема | Исправление | Проверка |
| --- | --- | --- |
| Variants изменял `content_bucket` у посторонней auth-коллекции только из-за совпадения имени поля | Принадлежность поля определяется опубликованной конфигурацией для конкретной auth-коллекции | Регрессионный тест сохранения и HTTP-редактирования пользовательского поля, включая нулевое значение |
| Установка Variants могла превратить обычную коллекцию приложения с зарезервированным именем в служебную | Совпадение с несистемной коллекцией отклоняется; автоматическое присвоение `System` удалено | Регрессионный тест отказа без изменения схемы |
| Браузерный тест смены типа полиморфной связи мог найти две кнопки Set selection во время анимации | Тест ждёт удаления предыдущего picker перед открытием следующего | Полный повторный прогон Playwright |

Убрано дублирование сравнения nullable API rules в Variants; используется одна проверка, сохраняющая различие между закрытым и открытым правилом. Уточнён контракт `Load` в GoDoc. Массовая перестройка остальных плагинов не потребовалась.

## Подготовка репозитория

- Module path и внутренние импорты приведены к `github.com/NikitaVasin/pocket_mfo`.
- Example и Docker используют локальные исходники того же модуля; это дополнительно проверено разрешением пакетов с отключённым Go proxy.
- Добавлены общий и четыре специализированных AGENTS.md, отдельный README Polymorphic Relation, CONTRIBUTING и инструкция публикации.
- Уточнены работа Singleton под Schema Lock и операторское восстановление бэкапа.
- Подготовлен GitHub Actions workflow для Go, браузера и Docker. Файлы окружения исключены из Git и Docker context.

## Выполненные проверки

- `go test -race ./...` — успешно.
- `go vet ./...` и `go build ./...` — успешно.
- `npm run test:browser` — 21 тест успешно, отдельные защищённый и обычный стенды, проверки обеих тем.
- `npm run test:docker` — успешно: сборка, healthcheck, embedded UI, expand, Singleton, сохранение изменений и отсутствие повторного seed после рестарта. Временные ресурсы удалены самим тестом.
- `git diff --check` и локальные ссылки в документации — без ошибок.

Проверки выполнены локально. Запуск workflow на GitHub произойдёт после отправки файлов. Лицензия и версия первого релиза остаются решениями владельца; лицензия не добавлена. Коммит, push и тег в рамках этой подготовки не создавались.
