Как проверить интеграцию

Откройте оффер в приложении. Здесь появится переход, а браузер откроет Google. Выберите статус заявки — кабинет отправит постбек в Pocket MFO.

Пока нет переходов

Откройте демонстрационный оффер из Flutter-примера.
Один выданный токен соответствует одной заявке.

Статус хранится у партнёра независимо от доставки. Ошибочный постбек можно повторить вручную. Повтор успешного постбека может повторно начислить Revenue.

Изменить конверсию

Сумма — выплата вебмастеру, а не сумма займа. Для отдельного события создания заявки сначала отправьте «Новая заявка». Статус Revenue выбирается в настройках провайдера Pocket MFO.

Настройки постбеков

Куда отправлять изменения заявок. При общем запуске Compose используйте внутреннее имя сервиса pocketbase:8090.

Поля и статусы постбека

Эти поля уже сопоставлены у провайдера demo в Pocket MFO.

subid
Токен перехода из ссылки
lead_id
Постоянный ID заявки партнёра
status
lead, hold, approved, rejected
event_id
ID изменения статуса
timestamp
Время изменения, Unix seconds
amount / currency
Вознаграждение и валюта

В Pocket MFO должны быть указаны ваши Application ID и Post API key AppMetrica. Здесь ключ AppMetrica не нужен.
