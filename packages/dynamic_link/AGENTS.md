# Пакет dynamic_link

- Используй пакет для платформонезависимого описания ссылки в domain, data,
  backend и тестах.
- Публичный API находится в `lib/dynamic_link.dart`; внутренние файлы `src`
  других пакетов не импортируй.
- Не добавляй сюда Flutter, навигацию, WebView, DTO конкретного backend или
  бизнес-правила приложения.
- Новые поля обязаны участвовать в equality и иметь unit-тест.
- Flutter-исполнение режимов находится в соседнем `dynamic_link_flutter`.
