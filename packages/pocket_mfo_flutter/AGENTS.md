# Единая Flutter-интеграция

- PocketMfo использует переданный PocketBase/authStore; не создавайте второй клиент и не меняйте владельца SDK.
- Profile ID всегда user.id. Гости используют штатные create/authWithPassword, без отдельного Go-плагина. Сначала сохраняйте секрет, потом делайте запросы; сетевые ошибки не создают нового пользователя.
- Сериализуйте смену SDK профиля и события. Снимок экспериментов из /api/variants/me привязан к пользователю, хранится только в памяти; никаких запросов на каждое событие.
- Нижние пакеты сохраняют самостоятельные API. Ссылки не открывайте заранее; пуш ждёт авторизации и Navigator.
- Проверяйте гонки, восстановление/офлайн, таймаут и резервный снимок, отсутствие лишней активации SDK и холодный пуш. Нативные зависимости подменяйте адаптерами.

- Для воронок передавайте exposures из реально показанных записей в reportEvent и resolve/openPartnerLink. Сохраняйте variantContext рядом с показанной моделью; не заменяйте его текущим назначением после смены группы. Подписанный token не отправляйте в AppMetrica.
