# Push Links Flutter

- Адаптер callback для двух действий: `route/url` и `partner/id`.
- Обычный маршрут передаётся приложению. Партнёрская ссылка запрашивается через существующий PocketBase с его authStore.
- Во время resolve ничего не показывайте. При ошибке, невалидном ответе или отсутствии ссылки оставляйте текущий экран без сообщений и индикаторов.
- Только успешный resolve открывает WebView через push на корневом Navigator. Не заменяйте страницы и не сбрасывайте существующий стек.
- Сохраняйте warning dialog и WebView-политики ссылки. Не запрашивайте redirect заранее, не отправляйте второй клик, не добавляйте автоматические повторы.
- До запроса дождитесь `beforeOpen`; после dispose не открывайте поздний ответ. Эти случаи и сохранение вложенной навигации проверяйте widget-тестами в обеих темах.
