# AppMetrica

Общий Go-плагин PocketBase; контракт — [README.md](README.md).

- Регистрируйте перед потребителями и Bootstrap. Partner Links и Push импортируют этот пакет; обратных импортов нет.
- Секреты доступны только доверенному Load. Админский ответ содержит признаки наличия. Не логируйте OAuth, Post API key или исходные ответы служб.
- Служебные данные и схема защищены приватным контекстом; HTTP-скрытие не заменяет проверки. Configure транзакционный и проверяет Version, Managed и защиту привязок Application ID.
- Миграция при конфликте идентификаторов должна откатываться. Не выбирайте молча один ID и не переимпортируйте старые настройки после первого переноса.
- Проверка готовности только читает: без событий, Revenue, создания групп и отправки пушей. Заполненность, чтение API и реальная доставка — разные состояния.
- Новые маршруты разрешайте в Schema Lock точно по методу/шаблону. Проверяйте обычного пользователя, суперпользователя, отказ без побочных изменений, миграцию/откат и обе темы UI.
- Не добавляйте загрузку Firebase через недокументированный внутренний API кабинета.
