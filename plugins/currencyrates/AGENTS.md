# Currency Rates

Сначала прочитайте корневой `AGENTS.md` и `README.md` этого плагина.

- `Register(app)` вызывается до Bootstrap/Start, Schema Lock — после него. В Bootstrap только локальная установка схемы, HTTP выполняется в OnServe/cron или `Plugin.Update`.
- Источник — официальный XML_daily ЦБ РФ по HTTPS. Дату запроса определяйте по Москве, дату записи берите из XML. Учитывайте Windows-1251, десятичную запятую и номинал.
- `currency_rates` — системная коллекция с публичным чтением. Записи и схема изменяются только внутренними операциями плагина. Не экспортируйте внутренний контекст и не ослабляйте проверки для суперпользователей.
- Пара `date, currency` уникальна. Сначала валидируйте весь ответ, затем сохраняйте в транзакции через `tx`. Сохраняйте существующие ID при повторной загрузке.
- История ограничена пятью календарными годами от московского дня; запись ровно на границе остаётся. Очистка должна работать и при отказе ЦБ, атомарно и без загрузки всей истории в память.
- Тестируйте номинал, кодировку, повторную загрузку, выходной день, повреждённый ответ, откат импорта и очистки, границы retention и HTTP-запреты для пользователя/суперпользователя с Schema Lock и без него.
- Не добавляйте скрытую сетевую зависимость в тесты: используйте HTTP transport с фикстурами.
