# Currency Rates

Отдельный плагин PocketBase с официальными курсами валют Банка России к рублю. Источник — [XML-сервис ЦБ РФ](https://www.cbr.ru/development/sxml/), `https://www.cbr.ru/scripts/XML_daily.asp?date_req=DD/MM/YYYY`. Ключи не требуются.

```go
import "github.com/NikitaVasin/pocket_mfo/plugins/currencyrates"

rates := currencyrates.Register(app) // до Bootstrap/Start, перед Schema Lock
```

При Bootstrap создаётся системная коллекция **`currency_rates`**, доступная обычной таблицей в админке. При запуске `serve` загружаются курсы на текущий московский день. Затем cron `currencyrates_update` повторяет загрузку ежедневно в **03:00 UTC / 06:00 МСК** при стандартном часовом поясе cron PocketBase. Если приложение меняет часовой пояс общего cron, расписание следует ему. Сервер должен работать в момент запуска задания.

Первый запрос может задержать запуск сервера максимум на сетевой таймаут 15 секунд. Недоступность ЦБ не останавливает сервер: ошибка записывается в лог, сохранённые курсы остаются доступными, следующая попытка — по расписанию или после перезапуска. Задание можно запустить вручную в штатном разделе Cron админки.

История **накапливается с момента подключения**: первоначальная загрузка архива и восстановление дней простоя не выполняются. На выходных и праздниках ЦБ может вернуть предыдущую дату действия. Сохраняется именно дата из XML; искусственные записи на каждый календарный день не создаются. RUB не добавляется: таблица содержит валюты, вернувшиеся в ответе ЦБ.

| Поле | Значение |
| --- | --- |
| `date` | Дата действия курса из ЦБ, календарная дата в виде `YYYY-MM-DD 00:00:00.000Z` |
| `currency` | Буквенный код валюты, например USD, EUR, CNY |
| `numCode` | Трёхзначный цифровой код, строка с сохранением ведущих нулей |
| `cbrId` | Идентификатор валюты в ЦБ |
| `name` | Русское название из ЦБ |
| `nominal` | Количество единиц валюты, например 1, 10, 100 |
| `value` | Стоимость указанного номинала в рублях |
| `rate` | Рублей за **одну** единицу валюты: `value / nominal` |

Пара `(date, currency)` уникальна. Повторная загрузка обновляет ту же запись, сохраняя ID. Весь ответ проверяется до записи и сохраняется одной транзакцией. Ошибка в XML или одной валюте не оставляет частично обновлённый день. Windows-1251 поддерживается; размер ответа ограничен 2 МиБ. Числовые поля PocketBase используют float64: при денежных расчётах отдельно задавайте нужное округление.

После каждой попытки обновления, в том числе неудачной, удаляются записи с `date` **раньше даты пять календарных лет назад** по московскому дню. Записи ровно на границе сохраняются. Для 29 февраля граница в невисокосном году — 28 февраля. Очистка атомарна и не зависит от доступности ЦБ; при выключенном сервере выполняется при следующем старте.

Чтение через обычный Records API открыто гостям и пользователям. Пример последних дат сначала:

```text
GET /api/collections/currency_rates/records?sort=-date,currency&perPage=100
```

Для последнего курса конкретной валюты используйте фильтр `currency = "USD"`, сортировку `-date` и `perPage=1`. Дата обязательна при интерпретации результата: при сбое источника последняя запись может быть старой.

Создание, изменение и удаление записей, очистка таблицы и изменение её схемы запрещены, включая суперпользователей и приложение без Schema Lock. Плагин не перехватывает существующую чужую коллекцию с именем `currency_rates`: Bootstrap завершится ошибкой без изменения её данных.

Для ручного запуска из Go:

```go
err := rates.Update(ctx) // после Bootstrap: импорт и очистка
removed, err := currencyrates.Cleanup(app) // только очистка
```

Проверки:

```sh
GOTOOLCHAIN=auto go test -race ./plugins/currencyrates
```

Тесты используют подменённый HTTP transport и временные базы, не зависят от доступности ЦБ.
