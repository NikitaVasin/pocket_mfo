# Dynamic Link

- Это самостоятельный тип поля PocketBase `dynamicLink`, не тип провайдера и не отдельная таблица.
- `Field` встраивает JSONField для хранения, но принимает только контракт `Value`: HTTP(S) URL, режим и типизированные параметры DynamicLink. Произвольный JSON запрещён.
- `PrepareValue` заполняет пропущенные параметры; явные false сохраняются. `ValidateValue` отклоняет неправильные типы, URL и режимы. Required и необязательный null сохраняют семантику PocketBase.
- Register до Bootstrap/Start; Регистрируется отдельно от Partner Links. Configure создаёт singleton-коллекцию настроек с Variants; до него зарегистрируйте эти два плагина. UI использует app.fieldTypes и штатный редактор записи. Не дублируйте форму записи или боковую панель.
- Сохраняйте публичное имя saveCooke. Обновление контракта синхронизируйте с Dart-пакетами и Partner Links.
- Нет сетевых запросов, переходов или отправки событий из этого поля.
- Проверяйте независимое использование поля, экспорт/загрузку схемы, явные false, ошибки без изменения данных и UI в обеих темах. Миграция старых partner_links относится к plugins/partnerlinks.
