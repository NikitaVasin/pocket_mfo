# MCP

- Это Go-плагин PocketBase. Официальный MCP SDK обслуживает Streamable HTTP; не заменяйте протокол самодельным RPC.
- `Register` до Start, провайдеры подключаются через `Server.Use(Provider)`. MCP не импортирует плагины-провайдеры. Имена инструментов уникальны; права ключей не расширяются автоматически.
- `mcp_keys` системная, закрытая для Records API/realtime/прямых записей. Только хеш токена, полное значение возвращается один раз. Проверяйте отзыв и срок на каждом запросе и перед выполнением инструмента. Не логируйте Authorization.
- HTTP key management только superuser. Контент: пересечение allowlist сервера и ключа, только несистемные base-коллекции и нескрытые поля. Операции идут через Records API с request hooks. Не открывайте SQL, произвольные HTTP endpoints, schema/auth/service writes или expand.
- Bearer keys — полномочия явно разрешённых инструментов, не имитация обычного пользователя. Провайдеры сохраняют свои проверки. Новый рабочий endpoint согласуйте с точной политикой Schema Lock.
- UI через штатный `t`/`store`, первый аргумент `t.tag` — props или null. Ключи не сохраняются в localStorage.
- Пресет «Только чтение» использует `Tool.ReadOnly`; «Полный доступ» выбирает все зарегистрированные инструменты. Оба ограничены серверным списком коллекций и сохраняют точные права на момент создания ключа; ручное редактирование разрешено.
- Проверки: MCP client handshake/list/call, read/write scopes, отзыв/expiry, Origin, отсутствие побочных записей при отказе; обе темы browser.
