# MCP для PocketBase

Отдельный Go-плагин: Streamable HTTP на `/api/mcp`, ключи в дополнительной вкладке **MCP**, подключаемые инструменты других плагинов. Используется официальный `modelcontextprotocol/go-sdk`.

```go
bridge := mcp.Register(app, mcp.Options{
    ContentCollections: []string{"offers", "partner_links"},
})
push.Register(app, push.Options{
    AuthCollections: []string{"users"},
    MCP: bridge,
})
schemalock.Register(app)
```

Вызывайте до `Bootstrap` / `Start`. У плагина нет зависимости от Push, Partner Links или Flutter. `push` самостоятельно реализует интерфейс `Provider`; без переданного `MCP` работает только его админка и HTTP API.

## Ключи и подключение

Вкладка MCP → название → разрешённые инструменты → коллекции контента → срок действия → «Создать ключ». Полное значение показывается **один раз**. В базе хранится SHA-256, а не сам ключ. «Отозвать» запрещает следующие запросы без перезапуска сервера. Удаление суперпользователя, создавшего ключ, также прекращает доступ.

Пресеты заполняют права одним нажатием:

- **Только чтение** — все подключённые инструменты с `ReadOnly: true` и все разрешённые сервером коллекции контента.
- **Полный доступ** — все подключённые инструменты и разрешённые коллекции, включая редактирование/удаление контента, запуск и тестирование рассылок.

После выбора можно снять отдельные права. Пресет фиксирует текущий список: новые инструменты/коллекции не добавляются в уже выданный ключ автоматически. Даже полный доступ не разрешает системные/auth-коллекции, изменение схемы или коллекции вне `ContentCollections`.

В MCP-клиенте задайте:

- URL: `https://YOUR_POCKETBASE/api/mcp`;
- транспорт: Streamable HTTP;
- заголовок: `Authorization: Bearer YOUR_MCP_KEY`.

Используйте HTTPS вне localhost. Это собственные MCP API keys, не OAuth-токены AppMetrica и не пароль суперпользователя. Клиент должен поддерживать настройку Bearer-заголовка; OAuth discovery плагин не реализует.

По умолчанию запросы с `Origin` запрещены, нативные MCP-клиенты работают без него. Для доверенного браузерного клиента явно задайте `AllowedOrigins` в Go. GET/DELETE MCP возвращают 405: сервер не держит сессии и SSE-подписки. POST обслуживает протокол официальным SDK. Размер запроса ограничен 1 MiB, обработчик инструмента получает контекст с таймаутом 30 секунд; реализации обязаны учитывать отмену.

## Контент

Встроены `content_schema`, `content_list`, `content_get`, `content_create`, `content_update`, `content_delete`.

Каждый инструмент разрешается ключу отдельно. Коллекция должна одновременно присутствовать в `Options.ContentCollections` и в правах ключа. Доступны только обычные base-коллекции. Системные коллекции, auth-коллекции, views, скрытые поля, пароли и изменение схемы недоступны. Произвольные SQL, HTTP-маршруты, expand и фильтры не принимаются. List возвращает по 50 записей, параметр `page`.

Сначала `content_schema({"collection":"offers"})`, затем, например:

```json
{"collection":"offers","data":{"title":"Новое предложение"}}
```

Операции выполняются с административными полномочиями владельца ключа **только внутри разрешённой коллекции** через настоящий Records API. Поэтому обычные пользовательские API rules не ограничивают редактора контента, а request/model hooks, проверки полей, Singleton и Variants продолжают работать. Право на relation-поле разрешает назначать ссылки, допустимые штатной валидацией PocketBase; отдельного ограничения на целевые ID нет. Не включайте в список коллекции с доверенными бизнес-полями, которые нельзя отдавать редактору.

Создание записи не является идемпотентным по умолчанию. Для повторяемого создания можно передать заранее выбранный валидный `data.id`; после потери ответа проверьте запись через `content_get`.

## Интерфейс для других плагинов

```go
type Provider interface {
    MCPTools() []mcp.Tool
}
```

`Tool` содержит `Name`, `Description`, `InputSchema`, признаки `ReadOnly`/`Idempotent` и `Handle(context.Context, mcp.Call) (any, error)`. В `Call` доступны текущий `core.App`, проверенные права ключа и исходные JSON-аргументы. `mcp.Decode` отклоняет неизвестные поля и дополнительный JSON; значения проверяет сам обработчик.

Зарегистрируйте реализацию через `bridge.Use(provider)` до Start, обработайте возвращаемую ошибку. Названия должны быть уникальны: например, `push_launch` или `catalog_publish`. Плагин обязан использовать общие с админкой доменные операции, проверять бизнес-инварианты, не возвращать секреты и самостоятельно ограничивать доступ к данным внутри инструмента. Выдача ключу инструмента — разрешение на всю документированную область действия этого инструмента; ограничения `Collections` относятся к встроенным `content_*`.

Установка нового провайдера не расширяет старые ключи автоматически: в них хранится точный список имён инструментов. Для новых прав создайте новый ключ и отзовите прежний.

## Проверки

`GOTOOLCHAIN=auto go test -race ./plugins/mcp` проверяет официальный MCP-клиент, права, штатные record hooks, Origin, срок действия, отзыв и отсутствие раскрытия ключей. Браузерный сценарий — `tests/browser/push-mcp.spec.js`.
