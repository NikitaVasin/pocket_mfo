# Partner Links

Go-плагин PocketBase для выдачи партнёрских ссылок с сохранением конверсий и передачи событий в AppMetrica. Публичный контракт и настройка — [README.md](README.md).

- Register вызывается до Bootstrap/Start, после Variants и до Schema Lock. Options задаёт разрешённые auth-коллекции и коллекции Variants. Шифрования токенов нет.
- `pl_config` — защищённая служебная коллекция. Читайте через Load, меняйте атомарно через Configure с текущей Version. Не раскрывайте секреты через Records API, realtime, ошибки или UI.
- `partner_links` — обычная коллекция; resolve обязан проверять ViewRule, включая Variants. userId и назначения берите с сервера; profileId всегда равен сохранённому userId; клиент его не передаёт.
- Токен — 32 случайных байта, base64url (43 символа). В БД только скрытый SHA-256 для поиска. Resolve создаёт одну pending-конверсию и сохраняет снимок клика до ответа. Одна выданная ссылка — одна заявка; непустой leadId нельзя менять или присваивать другой ссылке.
- `conversations` обязательна и системная, Variants для неё запрещены. В UI только нативный просмотр; HTTP-запись запрещена даже суперпользователям (Records API, batch, truncate), независимо от Schema Lock. Доверенный Go-код продолжает создавать/обновлять/очищать записи. Pending хранится 14 дней от выдачи по умолчанию, остальные статусы — бессрочно. Настраиваемые сроки в днях; 0 означает бессрочно. Для остальных TTL считается от серверного statusChangedAt; повторы не продлевают. Cron удаляет просроченные записи; эндпоинты проверяют срок до cron. Постбек никогда не создаёт отсутствующую конверсию.
- Истории/сырых постбеков, очереди, дедупликации событий или автоматических повторов нет. Revenue включается у провайдера и отправляется только для revenueStatus: approved (по умолчанию) или hold. Повторный запрос отправляет отдельное событие. Не синтезируйте lead из статуса.
- Клик: отправка максимум 2 секунды, затем редирект даже при ошибке. Постбек: секрет провайдера обязателен, 200 только после AppMetrica 200; при сбое 502.
- Эксперименты фиксируются в записи конверсии; при постбеке не пересчитываются. Application ID снимка должен совпадать с текущими настройками.
- Не логируйте токены, profileId, payload и секреты. Сохраняйте редактирование URL до штатного activity logger PocketBase, в том числе при отказах.
- `partner_links.link` — поле `dynamicLink` из plugins/dynamiclink. URL и настройки открытия — одно значение. Миграция url/opening атомарна и сохраняет явные false.
- UI использует штатный API PocketBase, не отдельную сборку. Добавление маршрутов требует точного разрешения в Schema Lock и регрессионных проверок.
- Dart-пакеты находятся в `packages/`; не меняйте оригиналы в `mfo_hub`. `dynamic_link` остаётся независимым от backend, интеграция находится в `partner_links_flutter`.

Проверки: `go test -race ./...`, `go vet ./...`, browser/Docker smoke, анализ и тесты всех трёх Dart/Flutter-пакетов. HTTP-тесты используют локальную AppMetrica-заглушку, не настоящие ключи.
