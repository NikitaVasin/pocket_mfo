# Typed Config

- Нативный Go-плагин PocketBase; `Register` до Bootstrap/Start. UI — карточки и формы, **никаких JSON-редакторов**. Контракт: [README](README.md).
- `Field` расширяет JSONField; Schema описывает блоки, свойства и именованные Definitions. Новые типы задаются миграциями, не произвольным кодом из HTTP. Schema.Version повышается при изменении контракта; все старые записи валидируются атомарно.
- JSON содержит ID/type/data; `tc_*` — настоящие скрытые relation companions, которыми управляют только модельные хуки. Поддерживайте инварианты при Save, SaveNoValidate, HTTP, удалении и откате. Прямую HTTP-запись companions запрещать, включая модификаторы; скрывать и для суперпользователя.
- При удалении источника удаляется целый зависимый верхний item, включая вложенные ссылки. Удаление item не удаляет источник. Коллекцию-источник нельзя удалить, пока она объявлена в схеме. Не допускать зависших циклов/обхода приватного контекста.
- Mapping только по явно разрешённым полям и типам, привязки по стабильным ID. Запрещены auth/view/system targets, hidden/JSON/custom поля и traversal. Чтение проверяет ViewRule источника; недоступность убирает весь блок. nil != пустое правило.
- Обычный Records API возвращает проекцию, суперпользователь — редактируемые ссылки. Enrich с Priority=100 завершается до подписи Variants. Не трактовать чтение как реальный показ.
- Не заявляйте универсальную композицию экспериментов: приложение объединяет контексты использованных конфигураций явно. Изменение источника требует обновления модели клиента.
- `GenerateDart` генерирует DTO ответа, не модели admin-write. При правке генератора обновите fixture тестом `go test ./plugins/typedconfig -run TestGenerateDart -update-typedconfig-dart` и проверьте анализ/исполнение Dart.
- UI использует штатный picker, кнопки, select и темы; не форкать админку. Проверять ввод без потери фокуса, вложенные списки, ссылки, перестановку, сохранение/отмену, светлую/тёмную темы и узкий экран.

При общих хуках обязательны полный Go race/vet, browser и Docker smoke из корневого AGENTS.md. Новые эндпоинты требуют отдельного согласования с Schema Lock; сейчас их нет.
